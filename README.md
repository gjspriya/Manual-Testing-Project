# Manual Testing Project – E-Commerce Web Application

## Project Overview
This project demonstrates end-to-end manual testing for an E-Commerce Web Application. It includes all major testing documents prepared during the testing lifecycle.

## Project Documents
- Test Plan
- Test Scenarios
- Test Cases (39+)
- Requirement Traceability Matrix (RTM)
- Defect Log

## Testing Types Covered
- Functional Testing
- UI Testing
- Regression Testing
- Positive Testing
- Negative Testing

## Tools Used
- Microsoft Excel
- Microsoft Word

## Responsibilities
- Prepared Test Plan
- Designed and executed test cases
- Logged and tracked defects
- Created RTM
- Performed test execution and reporting

## Repository
This repository is created for learning and portfolio purposes to demonstrate manual testing skills.
